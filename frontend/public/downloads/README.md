# Datasheet placeholders

The product sections link to PDF specification sheets by the filenames below.
Drop the real files here (same names) and the links start working — no code change needed.

- `ochsner-air-water-bg.pdf` — термопомпи въздух-вода
- `ochsner-ground-water-bg.pdf` — термопомпи земя-вода
- `ochsner-water-water-bg.pdf` — термопомпи вода-вода
- `ochsner-hot-water-bg.pdf` — термопомпи за топла вода

The filenames come from `datasheetUrl` in the backend seeder
(`backend/src/main/java/bg/ochsner/site/config/CatalogSeeder.java`).
